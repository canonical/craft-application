# Contributing

Craft Application welcomes contributions from the community.

Before you start, please read the [Ubuntu Code of Conduct](https://ubuntu.com/community/ethos/code-of-conduct)
and the [Canonical Contributor License Agreement](http://www.ubuntu.com/legal/contributors).

## Development setup

```bash
make setup
make lint
make test
```

## Reporting issues

Open issues in the [Craft Application repository](https://github.com/canonical/craft-application/issues).
If you want to work on a change, comment on the issue first so maintainers can confirm
the scope.

## Pull requests

Open PRs against [canonical/craft-application](https://github.com/canonical/craft-application/compare).
Keep changes small, include tests when needed, and update documentation when behavior
changes.
